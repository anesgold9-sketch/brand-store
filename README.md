# Brand Store

متجر إلكتروني بسيط وقابل للتخصيص مبني باستخدام PHP Native مع بنية MVC. المشروع يتيح عرض المنتجات، استقبال الطلبات من الزبائن، وإدارة المنتجات والطلبات من لوحة تحكم المسؤول.

## نظرة عامة

هذا المشروع مصمم لتكون نقطة بداية قوية لبناء متجر إلكتروني صغير أو متوسط. ويوفر:

- واجهة متجر للزبائن لعرض المنتجات
- إمكانية إضافة الطلبات من الواجهة الأمامية
- لوحة تحكم للإدارة
- إدارة المنتجات من خلال إنشاء وحذف المنتجات
- إدارة الطلبات وعرض تفاصيلها وتحديث حالتها
- اتصال آمن بقاعدة البيانات عبر PDO

## التقنيات المستخدمة

- PHP 8+
- MySQL
- MVC Architecture
- PDO
- HTML / CSS / JavaScript

## مميزات المشروع

- عرض قائمة المنتجات

- استقبال طلبات العملاء

## متطلبات التشغيل

قبل تشغيل المشروع تأكد من وجود:

- PHP 8+
- MySQL
- Apache أو XAMPP
- Git

## التشغيل محلياً

1. انسخ المشروع داخل مجلد `htdocs` في XAMPP.
2. أنشئ قاعدة بيانات باسم `brand_store`.
3. استورد ملف SQL الموجود في `database/database.sql` إلى قاعدة البيانات.
4. افتح ملف `app/Core/database.php` أو `config/database.php` وفقاً للإصدار الحالي في المشروع، وتأكد من بيانات الاتصال:

```php
$host = 'localhost';
$dbname = 'brand_store';
$username = 'root';
$password = '';
```

5. ابدأ Apache و MySQL من XAMPP.
6. افتح المتصفح وقم بزيارة:

```text
http://localhost/brand-store/
```

## الوصول إلى لوحة التحكم

يمكن الوصول إلى لوحة التحكم عبر الروابط التالية:

```text
http://localhost/brand-store/admin/products
http://localhost/brand-store/admin/orders
```

## مسارات المشروع

### الواجهة الأمامية

- `/brand-store/` → الصفحة الرئيسية
- `/brand-store/products` → عرض المنتجات
- `/brand-store/product?id=1` → عرض تفاصيل منتج
- `/brand-store/about` → صفحة حول المشروع
- `/brand-store/order/store` → حفظ الطلب

### لوحة التحكم

- `/brand-store/admin/products` → قائمة المنتجات
- `/brand-store/admin/products/create` → إنشاء منتج جديد
- `/brand-store/admin/products/delete?id=1` → حذف منتج
- `/brand-store/admin/orders` → قائمة الطلبات
- `/brand-store/admin/orders/show?id=1` → تفاصيل الطلب
- `/brand-store/admin/orders/update-status` → تحديث حالة الطلب

## كيفية الاستخدام

### إضافة منتج جديد

1. اذهب إلى صفحة إنشاء المنتج.
2. أدخل اسم المنتج والسعر والكمية والوصف.
3. اختر صورة المنتج إذا رغبت.
4. احفظ المنتج.

### إدارة الطلبات

1. افتح صفحة الطلبات في لوحة التحكم.
2. اختر الطلب الذي تريد عرضه.
3. قم بتحديث حالة الطلب حسب الحاجة.

## ملاحظات مهمة

- قد تحتاج إلى ضبط مسار التطبيق اعتماداً على اسم مجلد المشروع داخل `htdocs`.
- إذا وجدت مشكلة في المسارات، تأكد من أن اسم المشروع في الروابط يتطابق مع اسم مجلد المشروع الذي قمت بنسخه.
- بعض الملفات أو الصور قد تكون محدثة داخل المشروع، لذا تأكد من مراجعة محتويات `public/assets/images` قبل الاستخدام.
