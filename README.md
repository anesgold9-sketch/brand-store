# متجر دار الأصالة - Brand Store MVC

متجر إلكتروني متكامل لإدارة الطلبات والمنتجات مع لوحة تحكم كاملة وخصم تلقائي للمخزون.

## المميزات
- عرض المنتجات وتقديم الطلبات (الدفع عند الاستلام).
- خصم تلقائي للمخزون عند إتمام الشراء.
- لوحة تحكم كاملة لإدارة المنتجات والطلبات.
- بنية MVC مع اتصالات PDO آمنة.

## التشغيل محلياً
1. ضع المشروع في مجلد `htdocs`.
2. استورد قاعدة البيانات من المسار: `database/database.sql`.
3. قم بضبط الاتصال في `app/Core/Database.php`.
